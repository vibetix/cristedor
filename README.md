# Cristedor

Cristedor is a modern corporate and portfolio website for Cristedor Group, built with React, TypeScript, and Vite. The project presents the company’s divisions, investment ecosystem, leadership, news, careers, and contact information through a polished digital experience.

## Overview

This project was designed as a high-end brand and investor-facing website, blending corporate storytelling with product showcase patterns and dynamic portfolio browsing. The site includes:

- Landing page and corporate narrative sections
- Portfolio and venture directory
- Divisions and ecosystem presentation
- Company news and leadership highlights
- Careers and application flow
- Contact and privacy pages
- Theme toggle and custom UI interactions

## Tech Stack

- React 18
- TypeScript
- Vite
- CSS Modules / custom styling
- Leaflet for map-related features
- Lucide React for icons

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

The application will run in development mode using Vite.

### Production build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
